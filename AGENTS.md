# Работа над A Hobo's Reveng

## Актуальные указания автора — 6 ноября 2026

- Код должен быть понятен второму разработчику без истории чата: небольшие классы, явные обязанности, читаемые имена и документация.
- Не смешивать звук, ввод, UI, отрисовку и правила боя в одном классе. `CampaignGame` только собирает зависимости и передаёт обновление.
- Сохранять текущую функциональность при рефакторинге. Расширение полной кампании отложено; после структуры кода приоритет — ассеты первой главы.
- По прямой просьбе автора **не запускать тесты, игровые прогоны и поиск багов**. Команда проверит игру самостоятельно. Старое требование обязательного запуска после каждого изменения этой просьбой отменено.
- Не выдавать результаты прошлых проверок за проверку новых изменений. В отчёте прямо указывать, если изменения не запускались.
- Доступ к компьютеру разрешён, но для файлов и приложений предпочитать API/CLI без ненужного переключения окон.
- Для новых участников поддерживать `Documentation/DEVELOPER-START-HERE.md` и `Documentation/ARCHITECTURE.md`.

## Формат кода

- Один основной тип на файл; каталоги по ответственности.
- Осмысленные имена, обычные многострочные методы, константы для значимых чисел.
- Комментарии объясняют ограничения и причины решений, а не пересказывают каждую строку.
- Формат сериализованных данных не менять случайным переименованием полей.
- Не вводить общие singleton-менеджеры или абстракции без конкретной потребности.
